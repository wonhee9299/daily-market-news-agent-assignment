# Claude Code 데일리 시장뉴스 에이전트

증권 AI 교육의 **Claude Code 기반 나만의 업무 자동화 에이전트 기획 과제**를 위한 공개 예시 프로젝트입니다.

사용자가 산업·키워드·조사 기간을 입력하면 공개 뉴스를 수집하고, 중복 제거·주제 분류·요약·출처 표시를 거쳐 일일 브리핑 초안을 만드는 에이전트를 설계했습니다.

> 보안 원칙: 사내 문서, 고객정보, 미공개정보는 입력하지 않으며 공개된 뉴스와 공식 발표만 다룹니다.

## 과제 요구사항 대응

| 과제 요구 | 이 프로젝트의 대응 |
|---|---|
| Option A 시장/뉴스 리서치 | 특정 산업의 공개 뉴스를 일일 요약 |
| What | 수집 → 검증 → 중복 제거 → 분류 → 요약 → 저장 |
| Why | 반복 검색 시간 단축, 출처 표시 누락 방지, 형식 일관성 확보 |
| How | AI가 조사·초안, 사용자가 원문·수치·중요도를 검수 |
| System Prompt | [`SYSTEM_PROMPT.md`](SYSTEM_PROMPT.md) |
| 프로젝트 기획서 | [`AGENT_DESIGN.md`](AGENT_DESIGN.md) |

## 예상 입력과 출력

**입력**

- 조사 산업: 반도체, 2차전지, 금융 등
- 핵심 키워드
- 조사 기간
- 최대 기사 수

**출력**

- 오늘의 핵심 요약
- 중요 뉴스 목록과 원문 URL
- 시장동향·기업이슈·정책/규제 분류
- 사실과 AI 해석의 구분
- 사용자가 추가로 확인할 항목

## 폴더 구성

```text
.
├── AGENT_DESIGN.md       # What·Why·How 프로젝트 기획서
├── SYSTEM_PROMPT.md      # 에이전트 시스템 프롬프트
├── CLAUDE.md             # Claude Code 작업 규칙
├── input/request.json    # 사용자 요청 예시
├── input/articles.json   # 검증된 공개 기사 입력
├── src/build_brief.py    # 브리핑 문서 생성기
├── samples/              # 학습용 예시
└── SUBMISSION.md         # 교육사이트 제출 문구
```

## 한계

- 본 에이전트는 투자 판단을 대신하지 않습니다.
- 뉴스 요약은 누락·오해·시점 차이가 발생할 수 있으므로 원문 확인이 필수입니다.
- 실제 운영 시 저작권, 로봇 정책, API 약관, 호출 비용을 별도로 확인해야 합니다.
